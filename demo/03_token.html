입력에 GitHub 토큰로 보이는 비밀정보가 있어 마스킹했습니다. 해당 값은 저장하거나 외부 API 호출에 사용하지 않습니다.

  • 보안상 사용자가 채팅으로 준 토큰·키로는 조회하지 않으며, private 저장소는 조회할 수 없습니다.
  • 노출된 토큰은 지금 바로 폐기(revoke)하고 새로 발급하시길 권장합니다.
  • 공개 저장소라면 이름만 알려주시면 바로 분석해 드립니다. 예: 'LangGraph 지금 실무에 도입해도 괜찮아?', 'Qdrant vs Chroma 운영 환경 비교', 'Agentic RAG 최근 연구 동향'
